# In-game checklist

## Opening
- [ ] B, the backpack button and each bag button open and close the window
- [ ] Escape closes it; the close button closes it
- [ ] Opens by itself at a vendor and at a mailbox, closes when leaving
- [ ] No Blizzard bag frame shows at any time

## Items
- [ ] Right click uses, equips and sells; Shift-click splits; drag and drop works
- [ ] Ctrl-click dresses up, Shift-click links in chat
- [ ] Items used in combat work, no "blocked action" (`/console taintLog 1`)
- [ ] New items glow; quest items show their mark; cooldowns spin
- [ ] Junk shows the coin at a vendor and is grey when the option is on
- [ ] Item level on equipment; quality border on and off, both looks
- [ ] Search greys what does not match; cleared when the window closes

## Bags
- [ ] Reagent bag: apart (title + free count), with the rest, hidden
- [ ] No authenticator: 4 locked slots at the end and the add-slots button (its popup)
- [ ] Bag slots row: hover highlights that bag's items; drag a bag out and in;
      right click shows the game's bag options
- [ ] Sort button sorts; right click shows the cleanup options

## Characters
- [ ] Another character appears after it logs in once
- [ ] Its bags show read only, with tooltips; search filters them
- [ ] Tooltip counts per character and total; off in options
- [ ] Forgetting a character in options removes it

## Options
- [ ] Every change shows at once on the open bags, both looks
- [ ] Columns, item size, spacing, scale; lock position; reset position
- [ ] Profiles: new, copy, reset, delete; language switch rebuilds the window
